# PV-PP Scalar Reduction Proof Program

The Productive Value–Productive Power (PV-PP) Scalar Reduction Proof Program is maintained as a separate public repository.

The program contains the formal proof and reduction work examining the conditions under which PV-PP decision structures can, and cannot, be represented through scalar aggregation.

## Canonical Proof Repository

The authoritative public proof materials are maintained here:

https://github.com/AmundsenLance/PP-PV-Scalar-Reduction-Proof-Program

## Published Project Site

A web-facing presentation of the proof program is available here:

## Repository Relationship

The Scalar Reduction Proof Program is part of the broader PV-PP research program represented by this repository, but its files are intentionally not duplicated here.

Maintaining the proof materials in a single dedicated repository:

- preserves one authoritative public source;
- prevents version divergence between repositories;
- keeps the main PV-PP framework repository manageable; and
- allows the proof program to maintain its own documentation, release history, and supporting materials.

For formal proof and reduction materials, the dedicated Scalar Reduction Proof Program repository governs.
