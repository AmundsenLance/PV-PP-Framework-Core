# Productive Value–Productive Power (PV-PP) Framework

**Public framework release — August 2026**

The Productive Value–Productive Power (PV-PP) framework is a formal research framework for modeling productive value, productive power, decision-making, viability, cooperation, execution, and dynamic economic behavior.

This repository is a **curated public release** of the framework. It is not the complete private research archive. The repository is organized to make the current framework understandable to human readers, researchers, developers, and AI systems without requiring them to reconstruct the theory from older drafts, scattered papers, or superseded material.

## Start here

For a compact overview of the current architecture, begin with:

- `PV-PP Compact Architecture Skeleton v1.0`
- `AUTHORITY_AND_STATUS.md`
- the materials under `10 Core Framework`
- the operator specifications under `15 Operators`

The current Layer 2 decision sequence is:

`PPP → Φ → H → G → ℛ → Graph Layer / seed substrate → Π → Π completeness validation → Constraints → Domain Framing → Adequacy → Σ → ε`

The framework distinguishes actual persistent state, perceived decision state, Productive Power (PP), Productive Value (PV), retained realized value, viability, memory, retrieval, expectation, constraints, candidate construction, non-scalar selection, execution, and environmental realization.

## Repository organization

The public release is organized approximately as follows:

- `10 Core Framework` — core state, ontology, perception, PV/PP, viability, and framework-level architecture
- `15 Operators` — current operator specifications and supporting operator documents
- `20 Stack and Layer Governance` — ownership, stack order, interface governance, and architecture control
- `30 Applications and Extensions` — selected application and scaling material
- `40 Runtime and Execution Formalization` — selected runtime, sidecar, execution, and implementation material
- `45 Testing and Validation` — selected testing and validation records
- `50 Proof and Reduction Program` — selected scalar-reduction and formal proof material
- `60 Benchmarks and Simulations` — selected benchmark and simulation artifacts
- `84 Framework Documentation` — reader-facing framework documentation and implementation supplements

Some internal, exploratory, historical, unpublished, or journal-submission material is intentionally excluded from this public repository.

## Authority

This repository contains documents with different authority levels. Inclusion in the repository does **not** make every file canonical.

Current framework authority is determined by the owner-file structure and the status rules described in `AUTHORITY_AND_STATUS.md`.

When documents conflict, use the current owner files and current governance documents rather than older working drafts, historical benchmark notes, publication summaries, or legacy architecture.

## Release model

This repository is maintained as a **public snapshot** of the framework rather than as the private working master. The working research corpus remains outside GitHub. Public releases are assembled deliberately from the current project state.

See `RELEASE_NOTES.md` for the release baseline and known deferred work.

## Citation and use

The framework is under active development. When citing or analyzing PV-PP, identify the release or document version used and distinguish current framework authority from historical or exploratory material.

For questions about what a specific file controls, consult `AUTHORITY_AND_STATUS.md`.
